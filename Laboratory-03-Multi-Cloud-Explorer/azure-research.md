# Azure Research

## Brief Overview
Microsoft launched Azure in 2010, and it's grown into the second-biggest cloud platform out there. What sets it apart is how tightly it plugs into the Microsoft tools most businesses already use — Windows Server, Active Directory, Office 365, and so on.

## Global Infrastructure
Azure organizes its infrastructure into Regions and Availability Zones, then groups those into larger "Geographies" so companies can keep their data in specific countries for legal or compliance reasons. It currently runs 60+ regions, more than any other provider, which is a big selling point for global companies.

## Cloud Management Console
Azure Portal

## Four Core Services
1. Virtual Machines — for spinning up compute resources
2. Blob Storage — object storage, Azure's version of S3
3. Azure SQL Database — managed relational database
4. Azure Active Directory (now branded Entra ID) — identity and access management

## Three Advantages
1. **Seamless Microsoft integration** — companies already running Windows Server, AD, or Microsoft 365 can migrate to Azure with far less friction than switching to a competitor.
2. **Widest regional footprint** — more regions than AWS or GCP, which matters a lot for data residency laws and serving users close to home.
3. **Strong hybrid cloud support** — tools like Azure Arc make it easier for companies to run a mix of on-prem and cloud infrastructure instead of an all-or-nothing migration.

## Typical Enterprise Use Cases
Azure tends to be the default pick for large organizations, universities, and government agencies that are already deep in the Microsoft ecosystem — think a university running Windows Server and Active Directory that wants to move some services to the cloud without ripping out its existing setup. It's also popular for hybrid environments where a company isn't ready to go fully cloud-native yet.
