## Analysis Questions

1. **Which cloud provider offers the broadest range of services?**
AWS has the widest range of services overall, with over 200 offerings covering nearly every use case. Being first to market gave it more time to build out its catalog compared to Azure and GCP.

2. **Which provider best integrates with Microsoft technologies?**
Azure is the clear winner here since it's built by Microsoft itself. Companies already running Windows Server, Active Directory, or Microsoft 365 can move to Azure with minimal friction compared to switching to a different provider.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud takes this one — it created and open-sourced Kubernetes, so GKE is widely seen as the most mature managed Kubernetes service, and tools like Vertex AI and BigQuery make it a strong pick for AI/ML work.
