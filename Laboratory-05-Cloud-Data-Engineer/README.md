# Laboratory 05 — Cloud Data Engineer

## Mission Overview
This lab simulates a real-world cloud engineering task: deploying a proof-of-concept Object Storage environment for a client's photo-sharing application. Since containers are ephemeral, application data cannot be stored inside them — object storage provides a persistent, scalable alternative suited for storing large volumes of unstructured data like user-uploaded images.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects to the cloud
- Document cloud storage operations using Markdown
- Continue expanding a professional GitHub Cloud Computing Portfolio

## Tools Used
- Docker
- MinIO (S3-compatible Object Storage server)
- KillerCoda Ubuntu Playground
- GitHub
- Markdown

## Skills Learned
- Deploying a containerized storage service using environment variables for configuration
- Understanding the practical difference between Block, File, and Object Storage
- Using port forwarding to access a service running inside a remote sandbox
- Creating and managing storage buckets through a web console
- Documenting infrastructure deployment steps clearly for reproducibility
