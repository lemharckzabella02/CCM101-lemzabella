Final Reflection
1. Where I started

When I began Mission 1, I only had basic knowledge of Linux and cloud computing. I was still getting used to the terminal and how cloud systems work. Remembering commands and knowing what each one does was hard at first.

2. What I learned along the way

Over the missions, I picked up Linux commands, file permissions, virtualization, Docker, storage management, and Bash scripting. I also learned to schedule tasks with cron. Mission 10 taught me the most, since I had to bring everything from the earlier missions together into one working system.

3. What I built in Mission 10

I set up a cloud environment on Ubuntu Server running in VirtualBox. Using Docker Compose, I deployed Ghost with MySQL, set up persistent volumes, and protected the server with UFW. I also wrote a Bash script to back up the database and scheduled it to run every night at 2:00 AM. Each part keeps the application organized, secure, and easier to maintain.

4. Problems I faced and how I fixed them

I ran into problems with server connections, containers not starting, and restoring the database. To find the cause, I checked the container status, read the logs, and reviewed the server settings. I learned to work through problems one step at a time instead of restarting or changing everything right away.

5. What I would improve

I would add off-site backups, HTTPS, and monitoring with alerts. I would also make SSH more secure and back up the Ghost content. These changes would better protect the data and make the system ready for real use.

6. How I used AI

I used AI to understand commands, explain technical concepts, and help with errors. I still had to run the commands, set up the virtual machine, test the application, and check the results myself. This showed me that AI can support technical work, but the actual building and checking is up to me.

7. Final thoughts

From Mission 1 to Mission 10, I learned to work with Linux, deploy containerized applications, set up security, and automate backups. I now understand better how the parts of a cloud system connect and work together. I plan to use these skills in future projects, especially in system administration, cloud computing, and DevOps.
