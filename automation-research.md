# Automation Research: The Language of Automation

## Bash Script
A Bash script is a text file that contains Linux commands that run in order, allowing us to automate tasks instead of typing each command manually. The shebang line `#!/bin/bash` at the beginning tells Linux to use the Bash interpreter to execute the script.

## Variables
Variables store values, such as a folder path, using names like `$BACKUP_DIR`. They make scripts easier to maintain because we can change a value in one place instead of updating it throughout the script.

## Cron Job
A cron job is a scheduled task in Linux that runs automatically at a specified time or interval. It is useful in cloud operations because it can run backups, clean logs, and perform other routine tasks without requiring someone to start them manually.
