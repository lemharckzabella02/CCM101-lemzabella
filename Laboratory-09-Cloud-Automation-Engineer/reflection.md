
# Mission Reflection

**1. Why is automation critical at scale?**

When managing hundreds of cloud servers, doing tasks manually is too slow and can lead to mistakes. Automation allows every server to perform the same tasks in the correct order. It also saves time and allows engineers to focus on important work like improving security, solving problems, and managing infrastructure.

**2. Dangers of automation**

Automation can make work faster, but it can also multiply mistakes. For example, a destructive typo in a script scheduled to run on 1,000 servers could delete important files across many systems. This is why scripts should be tested on a small scale, reviewed carefully, and supported by backups and recovery plans.

**3. Bash script vs. Docker Compose YAML**

A Bash script is procedural because I write commands that execute step by step. Docker Compose YAML, which I used in Mission 6, is declarative because I describe the services and configurations I want Docker to manage. Bash provides flexibility for different tasks, while Docker Compose makes it easier to define and manage multi-container applications.
